# 🚀 OCS Manager: инструкция для новичков

[English](QUICKSTART.md) · **Русский** · [← к README](../README.ru.md)

Эта инструкция проведёт вас от покупки сервера до работающего VPN на телефоне
и компьютере. Опыт работы с Linux не нужен: достаточно уметь копировать
и вставлять команды. На всё уйдёт около 20–30 минут.

---

## Шаг 1. Арендуйте VPS

Подойдёт почти любой недорогой VPS. При заказе выберите:

- **ОС:** Ubuntu 24.04 (или Ubuntu 22.04, Debian 12);
- **ресурсы:** 1 ядро, от 1 ГБ ОЗУ и от 10 ГБ диска — более чем достаточно;
- **виртуализация:** лучше **KVM**. Если тариф на OpenVZ/LXC, убедитесь, что
  в панели хостинга включён **TUN/TAP**.

После оплаты хостинг пришлёт **IP-адрес** сервера и **пароль root** (или
предложит добавить SSH-ключ).

## Шаг 2. Настройте доменное имя (желательно)

С доменом можно получить настоящий сертификат Let's Encrypt — клиенты не будут
ругаться на «недоверенный сертификат».

1. Купите домен у любого регистратора или используйте поддомен своего
   (например, `vpn.example.com`).
2. В настройках DNS создайте запись **`A`**: имя `vpn`, значение — IP вашего сервера.
3. Подождите 5–30 минут, пока запись распространится.

> Нет домена? Можно обойтись без него — скрипт сделает самоподписанный
> сертификат. Клиент при первом подключении спросит, доверять ли серверу, —
> ответьте «да».

## Шаг 3. Подключитесь к серверу по SSH

- **Windows 10/11:** откройте «Терминал» или PowerShell.
- **macOS / Linux:** откройте «Терминал».

Введите (подставьте IP своего сервера):

```bash
ssh root@203.0.113.10
```

На вопрос `Are you sure you want to continue connecting?` ответьте `yes`,
затем введите пароль root. Символы пароля не отображаются — это нормально.

## Шаг 4. Запустите установку

Скопируйте и выполните две команды:

```bash
wget https://github.com/StasGUN/ocsmanager/releases/latest/download/install-ocserv.sh
sudo bash install-ocserv.sh
```

Скрипт задаст несколько вопросов на английском. Если сомневаетесь, нажимайте
**Enter**: будет выбран вариант по умолчанию.

| Вопрос на экране | Что это | Что ответить |
|---|---|---|
| `Server domain name` | Доменное имя | `vpn.example.com` из шага 2 |
| `VPN address pool` | Внутренняя сеть VPN | Просто **Enter** |
| `VPN user name` | Имя пользователя | Например, ваше имя латиницей: `ivan` |
| `Password for ...` | Пароль | Придумайте или нажмите Enter, и скрипт сгенерирует надёжный |
| `Enable camouflage?` | Маскировка сервера | **Enter** (да, рекомендуется) |
| `Camouflage secret` | Секрет для адреса | **Enter**: сгенерируется автоматически |
| `TLS certificate` | Тип сертификата | `1` (Let's Encrypt), если настроили домен; иначе `2` |
| `E-mail for Let's Encrypt` | Почта для уведомлений | Ваш e-mail или Enter |
| `Start the installation?` | Начать установку? | **Enter** |

Сборка займёт 5–15 минут. Не закрывайте окно терминала.

## Шаг 5. Сохраните итоговые данные

В конце появится зелёная надпись **INSTALLATION COMPLETED SUCCESSFULLY** и сводка.
**Скопируйте её в надёжное место** (менеджер паролей, заметки). Самое важное:

```
  User            : ivan
  Password        : Xy7...           <- сохраните, в открытом виде он больше нигде не хранится
  Server address to enter in the client:
      https://vpn.example.com/?a1B2c3D4e5F6g7H8
```

> ⚠️ **Адрес для клиента — со «секретом» после `/?`.** Если включён camouflage,
> просто `vpn.example.com` работать не будет: сервер притворится обычным сайтом.

## Шаг 6. Подключитесь к VPN

### 📱 Телефон (iPhone / Android)

1. Установите **Cisco Secure Client** из App Store или Google Play.
2. Откройте приложение → **Connections** → **Add VPN Connection**.
3. **Description:** любое имя, например `Мой VPN`.
4. **Server Address:** адрес из шага 5 *вместе с секретом*.
5. Сохраните, включите переключатель, введите логин и пароль.

### 💻 Компьютер (Windows / macOS)

1. Откройте в браузере `https://vpn.example.com:8443/` (без секрета).
2. Войдите с логином и паролем VPN и скачайте клиент для своей системы.
   *Клиент появится там, если администратор загрузил установщики в панели
   (см. шаг 7). Иначе установите Cisco Secure Client или
   [OpenConnect GUI](https://gui.openconnect-vpn.net/) самостоятельно.*
3. В клиенте введите адрес из шага 5 и нажмите **Connect**.

### 🐧 Linux

```bash
sudo apt install openconnect
sudo openconnect 'https://vpn.example.com/?a1B2c3D4e5F6g7H8'
```

**Проверка:** откройте любой сайт «узнать мой IP» — должен показаться IP вашего сервера.

## Шаг 7. Откройте панель администратора

1. **Подключитесь к VPN** — панель открывается только через него.
2. Откройте `https://vpn.example.com:8443/portal` и войдите под первым
   VPN-пользователем (из шага 5).

В панели можно:

- 👥 добавлять и удалять пользователей, менять пароли;
- 📊 смотреть трафик и историю подключений (нажмите на имя пользователя);
- 🔌 видеть и разрывать активные сессии;
- 📦 загружать установщики Cisco Secure Client для Windows и macOS;
- 🚫 управлять fail2ban: баны, белый список;
- 🔄 обновлять ОС, панель и ocserv, перезагружать сервер.

## Шаг 8. Обновления

Время от времени заходите в панель: карточка **«OCS Manager» → «Обновить панель»**.
Обновление проверяется по цифровой подписи, а при сбое панель сама вернётся
на прежнюю версию.

## ❓ Частые проблемы

<details>
<summary><b>Клиент не подключается / «сервер не найден»</b></summary>

- Проверьте, что в адресе есть секрет: `https://домен/?секрет`.
- Проверьте, что у хостинга нет своего файрвола, закрывающего порт **443**
  (TCP и UDP). Если есть — откройте порт в панели хостинга.
</details>

<details>
<summary><b>Панель администратора показывает 404</b></summary>

Так и задумано: панель открыта только при подключённом VPN. Подключитесь к VPN
и попробуйте снова. Если VPN не работает, создайте SSH-туннель:

```bash
ssh -L 8443:localhost:8443 root@vpn.example.com
```

и откройте `https://localhost:8443/portal`.
</details>

<details>
<summary><b>Браузер предупреждает о сертификате в панели</b></summary>

Если вы открываете панель по внутреннему адресу VPN (например,
`https://172.16.28.1:8443/portal`), предупреждение нормально: сертификат выдан
на домен, а не на IP. Можно продолжить или открыть панель по домену.
</details>

<details>
<summary><b>Портал на порту 8443 не открывается из офиса или гостевой Wi-Fi</b></summary>

Некоторые сети блокируют нестандартные порты. Сам VPN (порт 443) при этом
работает. Порт портала можно сменить: `sudo OC_PORTAL_PORT=<порт> bash install-ocserv.sh`.
</details>

<details>
<summary><b>Ошибка «/dev/net/tun is missing»</b></summary>

На сервере выключен TUN/TAP. Включите его в панели хостинга (или напишите
в поддержку) и запустите скрипт ещё раз.
</details>

<details>
<summary><b>Let's Encrypt не выдал сертификат</b></summary>

Обычно это значит, что запись `A` домена ещё не указывает на сервер или занят
порт 80. Скрипт в этом случае поставит самоподписанный сертификат. Когда DNS
заработает, просто запустите скрипт ещё раз — это безопасно.
</details>

<details>
<summary><b>Я забыл пароль</b></summary>

Смените его в панели или по SSH:

```bash
sudo ocpasswd -c /etc/ocserv/ocpasswd ivan
```
</details>

Не нашли ответ? Посмотрите журнал установки `/var/log/ocserv-install-<дата>.log`
и [создайте issue](https://github.com/StasGUN/ocsmanager/issues).
